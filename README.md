# El Grimorio de la Gárgola 🏰 — Apprends la grammaire espagnole avec Gargui

Un jeu d'apprentissage de la grammaire espagnole façon **Duolingo**, avec :

- 🗺️ **Un parcours d'apprentissage** : 3 unités (Orthographe & Accentuation, Présent de l'Indicatif, Subjonctif Présent) composées de nœuds à débloquer — théorie 📖, leçons ⭐ et examen d'unité 🏆.
- 🏰 **Gargui, la petite gargouille de pierre** : grands yeux brillants façon Chat Potté, avec plusieurs humeurs (repos, joie, tristesse, réflexion, célébration 🎉).
- 💚 **Gamification** : XP, cœurs (vies), série de jours (streak), bonus « sans faute », confettis de victoire. Relire la théorie recharge les cœurs.
- 📚 **Théorie complète et colorée** : code couleur systématique (syllabe tonique en rose, terminaisons en bleu, irrégularités en violet, bons exemples en vert, erreurs en rouge) et encadrés « Astuce de Gargui ».
- ✍️ **5 types d'exercices** : QCM, phrases à trous, réécriture avec accents (clavier espagnol intégré á é í ó ú ü ñ), classification de mots, traduction.

La progression est sauvegardée localement dans le navigateur (localStorage).

Fait par Ignacio Collado Rojas.

## Lancer en local

**Prérequis :** Node.js

1. Installer les dépendances :
   `npm install`
2. (Optionnel, pour les futures fonctionnalités IA) Définir `GEMINI_API_KEY` dans [.env.local](.env.local)
3. Lancer l'application :
   `npm run dev`
